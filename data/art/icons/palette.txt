# Room for Trouble - icon palette and colour-blind variants.
#
# FORMAT (shared by every file in data/art/icons/, read by src/ui/icons.gd and
# tools/icons/*.py):
#
#   palette base              shared palette keys every icon can use
#   <key> <#RRGGBB|transparent>   <comment>
#   end
#
#   variant <name>            colour remap applied by Icons.tinted(name, variant)
#   <#from> <#to>             <comment>       (matched by exact hex, any key)
#   end
#
#   icon <name> <size>        one icon; size is N (square) or WxH
#   <key> <#RRGGBB|transparent>   optional local key (overrides the palette)
#   <rows>                    exactly H rows of W keys, '.' = transparent
#   end
#
# Comments are lines that start with '# ' (hash + space) or are a lone '#';
# blank lines are ignored. Text after a palette/variant entry is a comment.
# Keys are single printable characters other than '#' and space.
#
# STYLE RULES (see tools/icons/preview.py lint):
#   * Every silhouette has a 1-px outline in ink k (or K/N on dark detail).
#   * Light comes from the top-left: light tint on top-left inner edge,
#     shade along the bottom-right inner edge.
#   * 2-4 fill colours + highlight per icon; shapes carry meaning, colour
#     only supports it. No letters or words are baked into icons.
#   * Semantic colours: warm = coral + sun, cold = sky + snowflake,
#     quiet = plum + sleeping moon, sound = gold + note, water = water + drop,
#     clean = cream + folded rectangle.
